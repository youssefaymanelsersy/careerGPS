# careerGPS

This project was created with [Better-T-Stack](https://github.com/AmanVarshney01/create-better-t-stack), a modern TypeScript stack that combines React, React Router, Express, TRPC, and more.

## Features

- **TypeScript** - For type safety and improved developer experience
- **React Router** - Declarative routing for React
- **TailwindCSS** - Utility-first CSS for rapid UI development
- **shadcn/ui** - Reusable UI components
- **Express** - Fast, unopinionated web framework
- **tRPC** - End-to-end type-safe APIs
- **Node.js** - Runtime environment
- **Drizzle** - TypeScript-first ORM
- **PostgreSQL** - Database engine
- **Authentication** - Better-Auth
- **Turborepo** - Optimized monorepo build system
- **Docker** - Containerized for production

## Getting Started

First, install the dependencies:

```bash
bun install
```

## Environment Variable Setup 

1. Create `apps/server/.env` and add:
```env
DATABASE_URL=
BETTER_AUTH_SECRET=
BETTER_AUTH_URL=
CORS_ORIGIN=
SERVER_URL=

CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=

AI_MICROSERVICE_URL=
AI_TEAM_PARSER_URL=
AI_TEAM_ATS_URL=
AI_TEAM_MATCHING_URL=
AI_INTERVIEW_SERVICE_URL=
AI_TEAM_SECRET=
GROQ_API_KEY=
HUGGING_FACE_CV_ATS_API_KEY=
HUGGING_FACE_SKILL_MATCHING_API_KEY=

VAPID_PUBLIC_KEY=
VAPID_PRIVATE_KEY=
RESEND_API_KEY=
```

2. Create `apps/web/.env` and add:
```env
VITE_SERVER_URL=
VITE_VAPID_PUBLIC_KEY=
```

## Database Setup

This project uses PostgreSQL with Drizzle ORM.

1. Make sure you have a PostgreSQL database set up.
2. Update your `apps/server/.env` file with your PostgreSQL connection details.
3. Apply the schema to your database:

```bash
bun run db:push
```

Then, run the development server:

```bash
bun run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to see the web application.
The API is running at [http://localhost:3000](http://localhost:3000).

## AI Microservices

To get the full application experience (including CV parsing, ATS scoring, and skill matching), you will also need to clone and run the AI Microservices repository alongside this project.

1. Clone the AI Microservices repository:
```bash
git clone <AI_REPO_URL>
```
2. Follow its README to start the FastAPI server.
3. Update the `AI_*` environment variables in `apps/server/.env` to point to your local microservice instances.

## Docker Deployment

You can quickly build and run the entire stack using Docker Compose. We've added convenient bun commands:

```bash
bun run docker:build
bun run docker:up
```

This will build both `careergps-server` and `careergps-web` and run them on their respective ports.

## Available Scripts

- `bun run dev`: Start all applications in development mode
- `bun run build`: Build all applications
- `bun run dev:web`: Start only the web application
- `bun run dev:server`: Start only the server
- `bun run check-types`: Check TypeScript types across all apps
- `bun run db:push`: Push schema changes to database
- `bun run db:generate`: Generate database client/types
- `bun run db:migrate`: Run database migrations
- `bun run db:studio`: Open database studio UI
- `bun run docker:build`: Build Docker images
- `bun run docker:up`: Start Docker containers in detached mode

## Frontend Environment Configuration

The frontend supports both build-time and runtime configuration.

Priority:

1. Runtime values injected via `window.__ENV__` (generated by `apps/web/docker-entrypoint.sh`)
2. Vite `import.meta.env` values (used for local development)

This allows a single frontend image to be deployed across multiple environments without rebuilding while preserving the local development workflow.
